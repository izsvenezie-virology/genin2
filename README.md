# Genin2

Genin2 is a lightning-fast bioinformatics tool to predict genotypes for clade 2.3.4.4b H5Nx viruses collected in Europe since October 2020. Genotypes are assigned using the methods described in [this article](https://doi.org/10.1093/ve/veae027).

## Recognized genotypes

You can inspect the up-to-date list of supported genotypes in [this file](src/genin2/compositions.tsv).

Genin2 can also distinguish the four sublineages of `EA-2024-DI`: `DI`, `DI.1`, `DI.2`, and `DI.2.1`.

## Documentation

Installation instructions, usage manual, and FAQs can be found on the sofware webpage at [https://izsvenezie-virology.github.io/genin2/](https://izsvenezie-virology.github.io/genin2/).
